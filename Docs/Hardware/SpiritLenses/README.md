# Spirit Lenses — hardware pack

Custom binocular AR glasses for Duel Monsters WRLDZ, built by **salvaging birdbath engines** and driving them from the Galaxy S23 Ultra.

| File | What |
|------|------|
| `00_WHAT_YOU_ARE_BUILDING.md` | Product, physics, paths A/B |
| `02_SALVAGE_HUNT.md` | Search language, donor ranking, what to pull |
| `03_BOM.md` | Harvest vs buy |
| `04_ASSEMBLY.md` | First light → jig → frame → wire |
| `05_BRINGUP.md` | S23 DeX, SBS, IMU |
| `schematics/SCH-01_system.svg` | Block diagram |
| `schematics/SCH-02_optical.svg` | Birdbath path + IPD |
| `schematics/SCH-03_electrical.svg` | USB-C DP / LT7911 / dual OLED / IMU |
| `schematics/SCH-04_mechanical.svg` | Frame pockets |
| `Spirit_Lenses_Build_Guide.pdf` | Printable set |

Rebuild drawings: `python3 schematics/make_schematics.py` then the export script.
