You will not see WRLDZ → Get Latest from GitHub until this
folder is replaced with a fresh GitHub copy. Missing menu = old copy.

1. Close Unity.
2. Download:
   https://github.com/GreatSaiyaDave/ProjectARGON/archive/refs/heads/main.zip
3. Extract it. Open the folder that contains Assets.
4. Unity Hub → Add → that folder. Open it (6000.5.10f1).
5. Top menu bar (File, Edit, Assets…): WRLDZ → Lab → Open Desktop Lab App

The Hub cloud icon is Unity Cloud (ads), not GitHub.
