WHY UNITY HUB LOOKS "SYNCED" BUT GITHUB IS NOT
==============================================

This project's Editor used to be set to "Unity Version Control"
(Plastic / UVCS). Hub's green / synced mark is that Unity cloud
(or a GitHub *link* in Hub 3.17). It is NOT an automatic download
of every commit Cloud Agents push to:

  https://github.com/GreatSaiyaDave/ProjectARGON

"Connected to source control" means Hub knows which repo the
folder is tied to. It does not pull when someone pushes main.

Hover the Hub source-control icon. The URL must be
GreatSaiyaDave/ProjectARGON. If it is Unity Version Control, or
a different GitHub repo, you are synced to the wrong place.

ONE-TIME FIX (Unity Hub 3.17+)
------------------------------
1. Close the Unity Editor.
2. Hub → Projects → Add → Add from repository.
3. Pick GitHub (sign in / PAT if asked).
4. Choose GreatSaiyaDave / ProjectARGON, branch main.
5. Wait for the clone. Open THAT project with 6000.5.10f1.
   Do not keep opening the old folder.

AFTER THAT, EACH UPDATE
-----------------------
In the Editor:  WRLDZ → Get Latest from GitHub
Then:           WRLDZ → Lab → Open Desktop Lab App

Title / Desktop Lab should not show a BUILD watermark.
Project search WRLDZ_BUILD must say CLEAN-0907.
Console (Unity log): [WRLDZ] BUILD CLEAN-0907

Project search WRLDZ_BUILD — if that file is missing, Hub is
still on the old copy.

ZIP FALLBACK (no git / Hub clone failed)
----------------------------------------
https://github.com/GreatSaiyaDave/ProjectARGON/archive/refs/heads/main.zip
Extract the folder that contains Assets + ProjectSettings.
Hub → Add that folder.
