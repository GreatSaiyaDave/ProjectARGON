Agents write to GitHub only. They cannot see or change the Unity
folder on your Linux machine. Hub linking GitHub is a bookmark,
not a download. That is why fixes you asked for never appeared.

Keep using:  …/DMWRDLZUnityProject/ProjectARGON
Do not Add a second folder. Do not unzip over this one.

The Hub cloud icon is Unity Cloud (ads), not GitHub.

Zip is last resort on a new machine only:
https://github.com/GreatSaiyaDave/ProjectARGON/archive/refs/heads/main.zip

1. Close Unity (File → Exit).
2. Open Linux Terminal — not the Unity Console. The Console cannot run git.
3. Type:  cd
   then a space, then drag your ProjectARGON folder onto the Terminal
   window, then press Enter.
4. Paste this one line, Enter:

curl -fsSL https://raw.githubusercontent.com/GreatSaiyaDave/ProjectARGON/main/Tools/get_latest_into_this_folder.sh | bash

That updates THIS folder. It refuses if Unity is open or if it
would overwrite your local edits.

To send YOUR folder TO GitHub (your work, kept, then uploaded):
Same Terminal steps 1–3, then paste:

curl -fsSL https://raw.githubusercontent.com/GreatSaiyaDave/ProjectARGON/main/Tools/send_this_folder_to_github.sh | bash

That saves this folder, keeps GitHub's files too, then uploads.
It will not wipe this folder. If GitHub asks you to sign in,
the script will say so.

If unstick already ran and this folder now has GitHub's files
instead of yours, close Unity first. Same folder. Paste:

curl -fL --show-error -o /tmp/wrldz-restore.sh https://raw.githubusercontent.com/GreatSaiyaDave/ProjectARGON/main/Tools/restore_pc_folder_from_before_unstick.sh && bash /tmp/wrldz-restore.sh

That puts THIS folder back to your saved local copy, then
removes leftover GitHub files and the Unity Library mix.
It does not change GitHub. First Play after that can be slow.
Do NOT use WRLDZ → Get Latest from GitHub after this.
That copies GitHub back onto this folder.

Unstick is the other direction (GitHub onto this PC). Only use it
if you want GitHub's files here. Same Terminal steps, then:

curl -fsSL https://raw.githubusercontent.com/GreatSaiyaDave/ProjectARGON/main/Tools/unstick_merge_keep_github.sh | bash

The CLEAN-0909 stamp is GitHub's copy. After restore, ignore that
stamp. Same Hub project → Play.

Later updates (only when you WANT GitHub's files on this PC):
WRLDZ → Get Latest from GitHub
WRLDZ → Send this folder to GitHub
