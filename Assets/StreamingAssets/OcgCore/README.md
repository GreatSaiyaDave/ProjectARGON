# StreamingAssets/OcgCore — AGPL-3.0-or-later (EDOPro / Ignis)

Full official `.cdb` (datas+texts), official CardScripts tree, speed table, provenance, Extra name index, and replay tapes. **Not Konami art.**

This folder is **lab-only**. Putting AGPL binaries/scripts here is **separation, not a distribution decision**. Linking/shipping likely copylefts ARGON until legal review.

Pins: `PROVENANCE.json`. Pool metadata: `lab_card_manifest.json` (`full_official_pool` CDB, `playPool: tcg_only`). Passcodes: `tcg_pool.json` (`datas.ot & 2`). Extra listing (not card data): `extra_index.csv`. Native plugin lives under `Assets/Plugins/x86_64/` (not this folder).

Loadable ≠ playable. Scripts: `scripts/` root libs + `scripts/official/`.

See `Assets/Scripts/WRLDZ/Duel/OCGCORE_LAB.md`.
