# WRLDZ free UI kit

Loaded at runtime by `FreeUiKit` from `StreamingAssets/UI/kit/`.

## Contents

| Folder | Source | License |
|--------|--------|---------|
| `buttons/`, `panels/` | [Kenney UI Pack](https://kenney.nl/assets/ui-pack) | **CC0** |
| `icons/` | [Kenney Game Icons](https://kenney.nl/assets/game-icons) | **CC0** |
| `audio/` | [Kenney UI Audio](https://kenney.nl/assets/ui-audio) | **CC0** |
| `fonts/Kenney Future*.ttf` | Kenney (with UI Pack) | **CC0** |
| `fonts/Orbitron-Bold.ttf` | [Google Fonts Orbitron](https://fonts.google.com/specimen/Orbitron) | **OFL 1.1** |
| `bg/*` | Generated for Project ARGON (neon gradient, hex, disk, glow) | Original |

See `LICENSES.txt`.

## How menus use this

- **Main Disk menu** (`DuelDiskMenuUI`) — full kit: bg, disk holo, Kenney panels/icons, fonts  
- **Duel UI** (`DuelUI`) — gradient bg, Kenney button panels, same fonts  
- Fonts also mirrored under `Assets/Resources/WRLDZ/Fonts/` so Unity can import them as Font assets
