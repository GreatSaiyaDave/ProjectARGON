# YgoRefs — reference library

Classic handheld/console YGO **reference** art (menus, maps, profiles).

**Runtime backgrounds do NOT use Master Duel / LOD Steam screenshots.**
Those were archived under `_archive_screenshots/` for design reference only.

Active runtime presentation lives in `../Presentation/` (original WRLDZ art).

| Still useful at runtime | Role |
|-------------------------|------|
| `map_domino.png`, `map_wc*` | Fallback overworld only |
| `profile_*.png` | Duelist portrait frames |
| `menu_dds_main.png` / eye crop | Emblem fallback |
| `ui-menus/`, `player-profiles/` | Full library |

Code: `YgoRefs` prefers `WrldzPresentation` for hub/splash/map.
