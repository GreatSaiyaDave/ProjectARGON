# WRLDZ UI Reskin — Battle City / Shadow Duel

Implements the reskin brief (ARGON development plan + lore).

## Visual system (`WrldzTheme`)
- Base: purple-black void  
- Accents: cyan, magenta, gold  
- Holographic panels with glowing edges  
- Story (parchment / Egyptian) stays **out** of overworld  

## Screens

| Screen | Scene | Role |
|--------|--------|------|
| Duel Standby splash | Boot | 3–5s cinematic handoff |
| DOB / Auth / Terms / Load | Boot | GO-style cascade (entry only) |
| **Main Map (HOME)** | Overworld | Tears, Anchors, avatar, HUD, center Disk **HUB** |
| **Mr. Referobot Hub** | MainMenu | Systems grid only (not home) |
| **Shadow Duel** | DuelSlice | Neon dual-disk TCG chrome; exit → map |

## Map loop
Tears → Shadow Duel → map · Anchors → reward stubs · Disk **HUB** → systems · MAP back to city · Duel **Map** → city.
